# Design System — aTour ("Aurora Wanderlust")

> Frontend design spec for aTour. Written for another Claude Code stack to build
> from. This is the **design source of truth** — read it before any UI work.
> Generated by /design-consultation on 2026-06-23.

## Product Context
- **What this is:** an AI-powered tour marketplace. Local guides post experiences
  (street-food walks, hikes, market tours); tourists search, book, and review them.
  Gemini powers natural-language search.
- **Who it's for:** tourists looking for authentic local experiences, and local
  guides monetizing what they know.
- **Space/industry:** travel / experiences marketplace (peers: Airbnb Experiences,
  GetYourGuide, Viator) — but warmer, more personal, indie.
- **Project type:** hybrid — an inspiring marketing landing + a functional booking app.
- **The one memorable thing:** *the world feels alive and within reach* — wanderlust
  you can act on in one tap.

## Stack & implementation notes
- React 19 + TypeScript + Vite + React Router. Hand-rolled CSS (no UI framework):
  design tokens live in `src/index.css` (`:root` CSS variables), component styles in
  `src/App.css`. Keep that split.
- **Everything below is expressed as CSS custom properties.** Define tokens in
  `index.css`; reference `var(--token)` everywhere. No hardcoded hex in components.
- **Relationship to current code:** the repo currently ships a calmer blue+coral
  system (Lexend / Source Sans 3). This spec is the *new target* — Aurora Wanderlust.
  Migrate the tokens in `index.css` first; existing components mostly reference
  semantic vars (`--surface`, `--border`, `--radius`, `--shadow`, `--accent`) so a
  token swap carries most of the way. Re-check contrast after the swap.
- Existing routes to restyle (do not rebuild logic): `/` home, `/discover` reels,
  `/posts/:id` detail+booking, `/bookings`, `/me` profile hub, `/me/posts` dashboard,
  `/create`, `/login`, `/register`.

## Aesthetic Direction
- **Direction:** Aurora Wanderlust — expressive, gradient-forward, editorially warm.
- **Decoration level:** expressive. Flowing aurora gradient meshes (northern-lights
  blends) are the brand signature. Vibrant per-destination accent hues. Generous,
  cinematic imagery.
- **Mood:** aspirational and alive, but premium not gaudy. The gradients carry
  "alive," the serif display carries "inspiring," disciplined app grids keep it
  trustworthy when money is involved.
- **The coherence rule:** expressive color demands calm type and disciplined layout.
  One aurora gradient per view, one warm CTA color, one accent hue per screen.

## Color

Approach: **expressive** — color is a primary design tool, but governed by rules.

### Aurora gradient (the signature)
The brand gradient. Use on the landing hero, section dividers, reels fallback panels,
and empty-state illustrations. Animate it drifting slowly (see Motion).

```css
--aurora-teal:    #2DD4BF;
--aurora-cyan:    #22D3EE;
--aurora-indigo:  #6366F1;
--aurora-violet:  #A855F7;
--aurora-magenta: #EC4899;
--aurora-amber:   #FB923C;

/* Canonical mesh — large, soft, multi-stop. */
--aurora-gradient: linear-gradient(
  120deg,
  var(--aurora-teal)   0%,
  var(--aurora-cyan)   22%,
  var(--aurora-indigo) 46%,
  var(--aurora-violet) 66%,
  var(--aurora-magenta)84%,
  var(--aurora-amber)  100%
);
/* Dark hero variant: same hues over twilight, lower opacity stops. */
```

### Action & ink
```css
--accent:        #FF6B5C;  /* sunset coral — THE booking/act-now CTA, used sparingly */
--accent-hover:  #F2543F;
--accent-soft:   #FFEDEA;

--ink:           #0E1726;  /* primary text on light */
--ink-soft:      #44506B;  /* secondary text */
--muted:         #6B7890;  /* tertiary / captions */
--twilight:      #0B1437;  /* deep navy — dark hero / reels surface */
--twilight-2:    #131E47;  /* raised dark surface */

--surface:       #FFFFFF;
--surface-soft:  #F4F7FF;  /* page background */
--border:        #E4E9F5;
--border-strong: #CBD5EC;
```

### Per-destination accent hues (one per category/view, never mixed on one screen)
```css
--cat-ocean:   #0EA5E9;  /* coastal / water */
--cat-jungle:  #10B981;  /* nature / hikes */
--cat-sunset:  #FF6B5C;  /* food / nightlife (shares the CTA coral) */
--cat-desert:  #F59E0B;  /* deserts / markets */
--cat-city:    #6366F1;  /* urban / culture */
```
A tour card / detail page picks ONE accent (by category, or a stable hash of the
post id when no category exists) for its chips, links, and focus ring.

### Semantic
```css
--ok:    #10B981;  --ok-soft:   #E7F8F1;
--warn:  #F59E0B;  --warn-soft: #FEF4E2;
--error: #E11D48;  --error-soft:#FDECEF;
--info:  #0EA5E9;  --info-soft: #E6F5FD;
```

### Contrast & dark mode
- Body text ≥ 4.5:1, large text ≥ 3:1. `--ink` on `--surface` passes; coral CTA uses
  white label text — verify ≥ 4.5:1 (darken to `--accent-hover` for text-on-coral if needed).
- On aurora/photo surfaces, always lay a dark scrim (`linear-gradient(transparent,
  rgba(11,20,55,.72))`) behind text. Never text directly on a raw gradient.
- Dark mode: surfaces become `--twilight` / `--twilight-2` (elevation by lightness),
  text off-white `#E6EAF5` (not pure white), aurora stops drop ~15% saturation.

## Typography

Replaces the current Lexend / Source Sans 3 pairing.

- **Display / Hero:** **Fraunces** (variable; use optical sizing + a soft, slightly
  high-contrast cut). Carries "inspiring travel" without going generic. Headings,
  hero, section titles, tour titles.
- **Body / UI:** **General Sans** (clean modern grotesk). Paragraphs, labels, buttons,
  nav, forms. If General Sans isn't available via the chosen font host, fall back to
  **Plus Jakarta Sans**.
- **Data / numbers:** **DM Sans** with `font-variant-numeric: tabular-nums` for prices,
  dates, ratings, dashboards.
- **Loading:** self-host or load via Fontsource/Bunny Fonts; `font-display: swap`;
  preconnect to the font origin; preload the Fraunces display weight used in the hero.

```css
--font-display: 'Fraunces', Georgia, serif;
--font-sans:    'General Sans', 'Plus Jakarta Sans', system-ui, sans-serif;
--font-data:    'DM Sans', var(--font-sans);
```

### Scale (modular, ~1.25 on body, larger jumps for display)
```
display-xl  clamp(2.75rem, 6vw, 4.5rem)  / 1.05  Fraunces 600  (hero)
display-lg  clamp(2rem, 4vw, 3rem)       / 1.1   Fraunces 600  (section titles)
h2          1.75rem / 1.15  Fraunces 600
h3          1.25rem / 1.2   Fraunces 600  (card/tour titles)
body-lg     1.125rem / 1.6  General Sans 400
body        1rem / 1.6      General Sans 400   (min 16px)
label       0.875rem / 1.4  General Sans 600
caption     0.75rem / 1.4   General Sans 500 (min 12px)
```
Use `text-wrap: balance` on headings, real curly quotes and `…`, tabular-nums on
number columns, no letterspacing on lowercase body.

## Spacing
- **Base unit:** 8px. **Density:** comfortable.
- **Scale:** `2xs 2 · xs 4 · sm 8 · md 16 · lg 24 · xl 32 · 2xl 48 · 3xl 64 · 4xl 96`.
- Related items close, sections far apart. Section vertical rhythm on landing: 64–96px.

## Layout
- **Approach:** hybrid.
  - **Marketing/landing + destination showcase:** creative-editorial. Full-bleed
    aurora heroes, asymmetric grids, overlapping cards, generous imagery.
  - **App surfaces (detail, booking, profile, dashboard, forms):** grid-disciplined.
    Calm, readable, max-width single column or simple grid.
- **Grid:** 12-col fluid; content max-width **1120px**; reading width **640px** for
  forms/text. Full-bleed sections break out of the container.
- **Border radius (hierarchical, not uniform):** `sm 8 · md 14 · lg 20 · xl 28 ·
  pill 9999`. Cards `lg`, inputs/buttons `md`, hero media `xl`, avatars/chips `pill`.
- **Breakpoints:** 375 / 768 / 1024 / 1440. Mobile-first.
- **Elevation:** `--shadow-sm` for cards at rest, `--shadow-lg` (tinted with indigo)
  on hover/active and for the booking panel.

## Motion
- **Approach:** intentional → expressive.
- **Easing:** enter `ease-out`, exit `ease-in`, move `ease-in-out`.
- **Duration:** micro 80ms · short 200ms · medium 320ms · long 600ms.
- **Signature motions:**
  1. Aurora gradient drifts slowly (~18s loop, `background-position` or animated mesh).
  2. Destination cards scroll-reveal (fade + 12px rise, staggered).
  3. Hover-lift on cards (translateY -4px + `--shadow-lg`).
  4. Reels scroll-snap between full-screen panels.
- Animate only `transform`/`opacity`/`background-position`. Never `transition: all`.
- **`prefers-reduced-motion: reduce`** → freeze the aurora animation, drop reveals to
  instant, keep functional transitions only.

## Pages & Components (build guidance)

### 1. Landing / Home (`/`) — the inspiring travel-agency page
The marquee page. Sections, top to bottom:
1. **Aurora hero** — full-bleed animated aurora over twilight. Fraunces display
   headline ("See the world through local eyes"), one supporting sentence, and the
   **trip-planner search** as the hero CTA (see #5). One coral secondary action
   ("Become a guide"). No cards in the hero.
2. **Destination showcase** — editorial grid of tour/destination cards (see #2),
   each with cover image and its category accent. Asymmetric: feature one large card.
3. **Booking preview teaser** — a single highlighted tour rendered as a mini
   booking-preview (image, title, price, next open date, "Book") to show the flow
   before sign-up.
4. **Traveler testimonials** (see #4).
5. **Trip-planner / Become-a-guide CTA band** — aurora band, dual CTA.
Keep the existing 3 feature points but restyle (no icon-in-colored-circle slop).

### 2. Destination / Tour showcase cards
- Cover image (16:9), category accent chip (pill, category hue), title (Fraunces h3),
  price + group size (DM Sans tabular), guide name + ★ rating.
- Hover-lift. Card radius `lg`. One accent hue per card by category.
- Image-less fallback: aurora gradient block (mirror the `/discover` fallback).

### 3. Tour detail + booking preview (`/posts/:id`)
- Two-column on desktop: left = gallery + description + guide card + reviews;
  right = **sticky booking panel** (`--shadow-lg`, radius `lg`): date picker over
  open slots, price (tabular), coral "Book" CTA, 409/auth states surfaced inline.
- Guide card: avatar, name, city, ★ avg rating, link to public profile.
- Reviews: each shows the **tour title + date** (data already on the booking),
  ★ rating, comment, author.

### 4. Traveler testimonials
- Quote cards: traveler avatar, name, the tour they took, ★ rating, short quote.
- Editorial layout (offset/overlap on desktop, stacked on mobile). Real reviews when
  available; this is the trust surface — keep it honest (only completed-tour reviews).

### 5. Trip planner / search CTA (Gemini NL search)
- Prominent natural-language search input ("Where do you want to wander?"), on the
  hero and as a sticky/secondary entry on browse. Submits to the AI search endpoint;
  show graceful keyword-fallback state. Coral submit. Suggestion chips below (popular
  destinations) using category hues.

### 6. Discover reels (`/discover`) — already built, restyle to target
- Full-bleed black surface, centered portrait column (max ~480px), scroll-snap panels.
- Cover image fills the panel; image-less → aurora gradient fallback. Bottom scrim +
  title (Fraunces), price (tabular), coral "View & book". Lazy-load images.
- Add a subtle aurora vignette at panel edges. Respect reduced-motion.

### 7. Profile hub (`/me`)
- Identity header card: name (Fraunces), city · member-since, ★ avg rating (if guide),
  bio. Then count pills linking to `/bookings`, `/me/posts`, `/create`.
- Calm, grid-disciplined. One accent (city indigo). No aurora here — keep it focused.

### 8. Create listing (`/create`)
- Single 640px form card (`--shadow`, radius `lg`): title, description, booking fee,
  max group size. Coral "Create listing". On publish → the new tour. Keep it a calm,
  uncluttered form — do not put it on the home page.

### 9. Guide dashboard (`/me/posts`), My bookings (`/bookings`)
- Grid-disciplined app surfaces. Booking rows show tour title (linked) + date + status
  badge; cancel/confirm/complete actions. Listing rows: publish/unpublish, manage
  slots. Status badges use semantic colors.

### 10. Auth (`/login`, `/register`)
- Centered 400px card on a soft aurora-tinted background. Labeled inputs (visible
  labels, not placeholder-only), clear focus ring (`box-shadow: 0 0 0 3px` accent-soft),
  coral submit, inline error states.

### Shared components & states
- **Buttons:** primary (coral, white label), secondary (ink outline / ghost), and a
  rare "aurora" button (gradient) reserved for the single hero/landing CTA only.
- **Nav:** logo top-left, top nav (Discover, Dashboard, My bookings, profile greeting).
  Sticky, translucent blur over content.
- **Empty / loading / error states:** every list (browse, bookings, discover, reviews)
  needs a designed empty state (warm message + action + small aurora visual), a
  skeleton matching the real layout, and a clear inline error with a retry path.
- **Focus visible** everywhere (never `outline:none` without a replacement ring).
  Touch targets ≥ 44px.

## Accessibility (non-negotiable)
- Text on any gradient/photo sits on a dark scrim. Contrast AA minimum.
- `prefers-reduced-motion` freezes aurora + reveals.
- Visible labels on all inputs; visible focus rings; 44px touch targets.
- Don't encode meaning in color alone (pair status color with text/icon).
- `color-scheme: dark` on `<html>` when dark surfaces are shown.

## Suggested build order (for the implementing stack)
1. Swap tokens in `index.css` to the Aurora palette + load Fraunces/General Sans/DM Sans.
2. Build the aurora hero + trip-planner search on `/`.
3. Restyle tour cards + destination showcase.
4. Tour detail sticky booking panel; testimonials section.
5. Restyle `/discover` reels to the aurora target.
6. Profile, create, dashboard, bookings, auth restyle.
7. Empty/loading/error states + reduced-motion + contrast audit pass.
