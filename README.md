# aTour

An AI-powered tour marketplace. Local guides post experiences (street-food walks,
hikes, market tours); tourists search, book, and review them. Natural-language
search is powered by Google Gemini, with a keyword fallback when the model is
unavailable.

## Status

The full v1 product loop is built and tested end to end:

- **Auth** — JWT register/login; one `User` table, role inferred from action
  (you become a *guide* by posting, a *tourist* by booking).
- **Listings** — post CRUD, max 5 per user, publish/unpublish, ordered images,
  public browse with `city` / fee filters.
- **Availability & booking** — date slots with capacity, booking lifecycle
  (`pending → confirmed → completed`, plus `cancelled`), self-book and full-slot
  guards.
- **Reviews** — one review per completed booking, with guide average rating.
- **AI search** — `POST /api/search/ai` ranks published posts for a
  natural-language query and returns a per-match reason (falls back to keyword
  search; can be switched off entirely).

Backend: 135 passing tests. Frontend: 19 passing tests.

## Stack

- **Backend:** FastAPI · SQLAlchemy 2.0 (typed) · PostgreSQL · Alembic ·
  `bcrypt` + `PyJWT` for auth · `google-genai` for AI search.
- **Frontend:** React 19 · TypeScript · Vite · React Router.
- **Tests:** pytest (`TestClient`) · Vitest + React Testing Library.
- **Local dev:** Docker Compose runs **Postgres only**; the backend (`uvicorn`)
  and frontend (`vite`) run directly on the host.

## Prerequisites

- Docker Desktop (for Postgres)
- Python 3.13+
- Node.js 20+
- A Google Gemini API key — optional; only needed for live AI ranking

## Run locally

### 1. Start Postgres

```bash
docker compose up -d        # Postgres on localhost:5432 (user/pass/db = atour)
```

### 2. Backend

```bash
cd backend
python -m venv venv
.\venv\Scripts\activate          # Windows PowerShell
# source venv/bin/activate       # macOS/Linux
pip install -r requirements.txt
```

Create `backend/.env`:

```ini
DATABASE_URL=postgresql://atour:atour@localhost:5432/atour
SECRET_KEY=change-me            # e.g. python -c "import secrets; print(secrets.token_hex(32))"
ACCESS_TOKEN_EXPIRE_MINUTES=30  # optional (default 30)
SEED_USER_EMAIL=seed@atour.local # optional
GEMINI_API_KEY=your-key-here    # optional — AI search falls back to keyword without it
GEMINI_MODEL=gemini-2.0-flash   # optional (default)
AI_SEARCH_ENABLED=true          # optional — set false to disable Gemini entirely
```

Apply migrations, seed, and serve:

```bash
alembic upgrade head
python -m scripts.seed
uvicorn app.main:app --reload --port 8000   # API + docs at http://localhost:8000/docs
```

### 3. Frontend

```bash
cd frontend
npm install
```

Create `frontend/.env`:

```ini
VITE_API_BASE_URL=http://localhost:8000
```

Then:

```bash
npm run dev                                 # http://localhost:5173
```

Register an account in the UI, create a listing, add dates, and book/review as
another user.

## Database migrations

```bash
# backend/, venv active, Postgres up
alembic upgrade head            # apply
alembic downgrade -1            # reverse the latest
alembic revision --autogenerate -m "describe change"   # after editing models
```

Always review autogenerated migrations before applying, and confirm `downgrade`
works. See `CLAUDE.md` for the full workflow.

## AI search notes

- `POST /api/search/ai` takes `{ "query": "...", "city": "optional" }` and
  returns up to 5 ranked posts, each with a `match_reason`, plus an
  `ai_available` flag.
- If Gemini errors (e.g. quota/billing) or `GEMINI_API_KEY` is unset, the
  endpoint degrades to keyword search and sets `ai_available: false`.
- Set `AI_SEARCH_ENABLED=false` to skip Gemini calls entirely (keyword-only).
